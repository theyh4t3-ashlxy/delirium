# quickshell

welcome to the asylum. this is the crown jewel of the desktop: a qml and c++ layer-shell monstrosity engineered to make electron devs cry and waybar users question their life choices.

we threw backward compatibility into a volcano. nerd font glyphs are dead to us; we migrated to google's official material symbols because life is too short for broken private-use-area codepoints and guessing which font patch broke your volume icon.

## what this thing actually controls
everything between your wallpaper and your eyeballs:
- dynamic status bar docked on any screen edge with live reordering
- concave liquid screen corners rendered via subsurfaces
- freedesktop toast notifications that actually respect physics
- pam-authenticated layer-shell lockscreen with live pipewire peak visualizers and extensionless state
- app launcher with category indexing, inline math calculation, and persistent pinned apps
- unified control center with sliders, toggles, and vibe settings
- wireplumber pipewire audio mixer with sink selectors
- wallpaper browser that extracts material palettes via matugen on the fly (and no longer nukes the event loop with 500 binding loops)
- zero `.json` architecture: all configurations, presets, and state files use flat `.conf` or extensionless key-value definitions

## file tree map
- `shell.qml`: root orchestrator. spawns bars, overlays, and registers ipc endpoints (`notifs`, `lock`, `caffeine`). do not touch unless you want a black screen.
- `Theme.qml`: dynamic material design token bible. generated by matugen. defines colors, metrics, and official material symbol codepoints.
- `settings.conf`: persisted user state. stores bar edge, widget layout, theme mode, and font settings.
- `bar/`: status bar layout engine. dynamic positioning, pill expansion, liquid corner docking.
- `corners/`: liquid concave screen corners and continuous display frame borders. sharp corners are illegal here.
- `presets/`: native `.conf` presets (`catalog.conf`, `default.conf`, `minimal.conf`, `island.conf`) mapping 1:1 with the settings engine.
- `widgets/`: modular desktop pills, sliders, drawers, and panels. the entire visual personality.
- `services/`: system state singletons (audio, network, battery, notifications, settings, presets, screen recording) talking to dbus and sysfs.
- `controls/`: custom design system components built from scratch because qtquick controls 2 is an abomination.
- `notifications/`: floating toast alerts that stack cleanly and dismiss on drag.
- `lockscreen/`: layer-shell pam authentication surface with native wave visualizer and extensionless state in `~/.config/quickshell/lockscreen/state`.
- `osd/`: on-screen volume and brightness pill popups so you know your keys actually worked.
- `scripts/`: python and zsh backend daemons handling clipboard history, session power actions, hardware battery probes, color picking, and audio mixers.

## how to run without burning your house down
```bash
# inspect active shell status and memory footprint
cli status

# gracefully reload without surface or layer-shell conflicts
cli reload

# switch between quickshell and brain_shell
cli shell toggle
```
